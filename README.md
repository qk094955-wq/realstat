# Real Estate Management Dashboard

An interactive, modern, and professional-looking Real Estate Management Dashboard built with **Python** and **Streamlit**. Designed specifically as a beginner-friendly, comprehensive university project for BS Computer Science or BS Data Science students.

---

## 🚀 Main Features
- **Professional Dashboard Overview:** Dynamic KPI cards for total properties, sales revenue, active rental income, and customer statistics.
- **Property Management:** Full CRUD operations (Add, View, Edit, Delete), search by ID/city/title, filters by type/status, and support for Pakistani Rupees (PKR).
- **Customer & Agent Management:** Client tracking, agent performance analytics, and automated commission calculations.
- **Inquiries & Viewings:** Manage potential buyers and schedule property viewings.
- **Sales & Transactions:** Record completed property sales and update availability automatically.
- **Rental Management:** Lease tracking, security deposits, and active rental agreements.
- **Payment Tracking:** Record payments, monitor pending balances, and handle partial payments.
- **Reports & Analytics:** Visual charts and CSV export functionality for all modules.

---

## 🛠️ Technologies Used
- **Python 3.9+**
- **Streamlit** (for interactive web UI)
- **Pandas** (for data tabular handling and analytics)
- **JSON** (for lightweight local persistence)
